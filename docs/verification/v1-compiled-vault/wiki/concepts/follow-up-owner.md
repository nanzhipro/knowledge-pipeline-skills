# 跟进责任人

运维备忘录将责任落实到一名检查完成情况、记录剩余不确定性的人；协议要求把此责任人随决策与证据记录。[原始提取](../../raw/s-b76b54779eb649390b45614d/v-f5e8d5dfbd9e1c3b/document.md)；[原始提取](../../raw/s-6a4c825bf681952fb6a8c5e2/v-e186c838e87fae7a/document.md)。

这是职责定义，不是已经完成任务的证据。
