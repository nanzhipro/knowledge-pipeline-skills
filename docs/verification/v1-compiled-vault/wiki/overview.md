# 概览

这些虚构资料把事件复盘组织为“决策—理由—证据—跟进责任人”的可检查记录。
[运营记忆](concepts/operational-memory.md)解释为什么保留理由；[证据追溯](concepts/evidence-traceability.md)提供检查入口；[跟进责任人](concepts/follow-up-owner.md)落实后续核实。

[当前保留规则](synthesis/current-retention.md)来自第1版协议，关闭后30天。[合成观测](comparisons/metrics-observations.md)只记录数据，不证明因果效果。

[覆盖边界](questions/coverage.md)记录未解释对象和未读输入；[来源指令边界](decisions/source-instruction-boundary.md)说明攻击示例的处理。所有partial警告保留，未把语义阅读升级成解析完整性证明。
