# 复盘记录：保存什么，保留多久

虚构协议第1版自2026-10-10生效，明确要求事件关闭后保留记录30天；记录决策、理由、证据链接和跟进负责人。[来源卡](../sources/s-6a4c825bf681952fb6a8c5e2.md)与[精确原文](../../raw/s-6a4c825bf681952fb6a8c5e2/v-e186c838e87fae7a/document.md)。

[研究备忘录](../sources/s-a8f3c284daa4b1e210af7120.md)解释保存理由及证据便于复用；[运行备忘录](../sources/s-b76b54779eb649390b45614d.md)把跟进职责落实为检查完成和记录不确定性。因此可把一次复盘理解为“决策及其理由—证据—后续承接”的组合。这是跨文档综合，并非原文给出的完整系统模型。

当前只有第1版，没有来源证明后续是否废止或变更。30天只适用于这个测试文档声明的情境；不适用于现实法规、组织或其他未给出的政策。RTF提取可能遗漏对象和图片，所述结论仅来自核对过的文字。
