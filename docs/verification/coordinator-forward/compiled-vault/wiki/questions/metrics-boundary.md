# 80%到85%能说明什么

[原始观测表](../../raw/s-976500503a908ad6da62ebe8/v-f262391723b01674/document.md)记录9月10次复盘、80%，10月12次复盘、85%，均明确为合成测试观测。可确定记录的百分比相差5个百分点；不能把测试值当真实组织表现。

未决问题：完成率的分子与分母是什么？10次和12次review_count是否等同该百分比分母？完成的判断时间与标准是否相同？样本如何选取？原表没有这些信息，无法判断趋势、显著性或因果改进。若后续文件出现不同数字，应先查是否改口径、修订或作用范围不同，再保留未解分歧。
