# 跟进负责人

虚构[协议](../sources/s-6a4c825bf681952fb6a8c5e2.md)要求记录跟进负责人；[运行备忘录](../sources/s-b76b54779eb649390b45614d.md)进一步说明每次复盘分配一人，检查完成情况并记录剩余不确定性。[运行原文](../../raw/s-b76b54779eb649390b45614d/v-f5e8d5dfbd9e1c3b/document.md)。

这些资料支持明确承接责任的工作定义，没有给出职务授权、升级机制或绩效评价标准，不能补写成完整治理制度。它连接[操作记忆](operational-memory.md)中的理由与[证据追溯](evidence-traceability.md)中的依据。
