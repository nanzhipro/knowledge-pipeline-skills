# 证据追溯

[简报](../sources/s-31acb4a56262cfe9ed33735a.md)与[研究备忘录](../sources/s-a8f3c284daa4b1e210af7120.md)都要求读者能访问主张背后的材料；[协议](../sources/s-6a4c825bf681952fb6a8c5e2.md)具体要求记录证据链接。这里将三种相合表述归为一个概念，而非把复制或多份同义资料当成独立实证。

本库的落实方式是来源卡连到精确raw快照及原件。文件哈希只标识字节，链接可达也不证明主张受支持。partial快照的遗漏与原文适用条件必须随引用保留。

与[操作记忆](operational-memory.md)配合，并给[跟进负责人](follow-up-owner.md)提供可复查依据。
