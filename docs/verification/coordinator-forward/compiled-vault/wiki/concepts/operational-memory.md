# 操作记忆

这里采用一个来自合成资料的工作定义：保存决策、作出决策的理由及相关证据，使后来者能检查其形成过程，并在新情境中应用或质疑。它超出只存一个结论，但本资料没有证明这是所有组织的唯一最佳做法。

[简报](../sources/s-31acb4a56262cfe9ed33735a.md)强调形成过程可检查；[研究备忘录](../sources/s-a8f3c284daa4b1e210af7120.md)强调记录可复用；[协议](../sources/s-6a4c825bf681952fb6a8c5e2.md)将其连接到具体复盘实践。[协议原文](../../raw/s-6a4c825bf681952fb6a8c5e2/v-e186c838e87fae7a/document.md)。

关系：[证据追溯](evidence-traceability.md)提供检查依据；[跟进负责人](follow-up-owner.md)使行动及剩余不确定性有明确承接者。
