# 同名文件不是同一资料

[研究备忘录](../sources/s-a8f3c284daa4b1e210af7120.md)有独立的SYNTHETIC-RESEARCH-MEMO文档ID，解释决策为什么形成及其证据如何复用；[运行备忘录](../sources/s-b76b54779eb649390b45614d.md)的ID为SYNTHETIC-OPERATIONS-MEMO，规定跟进完成及剩余不确定性。

二者路径、内容与原件哈希不同，概念互补。没有依据把后导入者视为修订版，或因同名memo.rtf而丢弃任何一个。当前资料未出现同一条件下相互否定的主张；后续出现矛盾时应保留来源与条件，不必为形成比较页而制造分歧。
