# 概览

这些虚构资料把事件复盘组织为“决策—理由—证据—跟进责任人”的可检查记录。
[运营记忆](concepts/operational-memory.md)、[证据追溯](concepts/evidence-traceability.md)和[跟进责任人](concepts/follow-up-owner.md)分别连接理解、检查和行动。

[当前保留规则](synthesis/current-retention.md)依据明确替代句更新为关闭后45天，2026-10-20生效；[旧规则](synthesis/retention-history-v1.md)保持历史可追溯。[合成观测](comparisons/metrics-observations.md)的10月85%与90%缺少修订解释，保留差异，不宣称改善。

[覆盖边界](questions/coverage.md)与[来源指令边界](decisions/source-instruction-boundary.md)继续有效。partial解析警告仍可见，扫描/损坏/不支持输入继续排除在知识依据之外。
